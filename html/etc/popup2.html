2024년
사용기관 2차 현행화 연장안내

현행화 안내사항
연장기간 :
2024.10.1.(화) - 10.13.(일)
  • 목적 : 올바른 정보 제공과 원활한 평생교육이용권 이용을 위한 사용기관 정보 최신화
  • 대상 : 전체 평생교육이용권 사용기관
  • 현행화 내용
    꼭 확인하세요.
    • 기관정보(주소, 연락처, 홈페이지 주소 등), 담당자 정보
    • 증빙자료(사업자등록증, 시설신고증, 24년 운영계획서 등)
    • 각종 서약서 전자서명
    • 2024년 기존 서약서 동의를 참여한 경우 별도 동의 필요 없음
      (단, 대표자가 변경된 경우 재동의 필요)
현행화 참여 방법
  • 현행화 참여버튼 클릭 후 [수정사항 없음] 또는 [수정하기-저장] 버튼을 꼭 눌러주세요
  • 현행화 참여여부 확인 방법 : 사용기관 정보에서 현행화 참여일자 확인
  • 현행화 미참여 시 연내 가맹번호 사용중지 예정
관련 문의사항
1600-3005
